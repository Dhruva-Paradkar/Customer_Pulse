# 📊 Customer Shopping Behaviour Analysis
Data analytics showing customer behaviour using powerbi, python, postgreSql.

## 1. Overview

This project focuses on analyzing customer shopping behaviour to identify purchasing patterns, customer preferences, spending trends, and factors influencing customer purchasing decisions.

The project follows an end-to-end Data Analytics workflow using Python, SQL, and Power BI. It involves loading and exploring the dataset, cleaning and transforming data, performing SQL-based analysis, and developing an interactive Power BI dashboard.

The objective is to transform raw customer data into meaningful insights that can help businesses understand customer behaviour and make data-driven decisions.

## 2. Dataset

**Dataset:** Customer Shopping Behaviour Dataset

The dataset contains customer shopping information, including demographics, purchased products, payment methods, discounts, subscriptions, and purchase frequency.

## 4. Project Workflow

### Step 1: Data Loading
- Imported the CSV dataset using Pandas.
- Examined the first few records.
- Checked dataset dimensions and column information.
- Generated descriptive statistics.

### Step 2: Exploratory Data Analysis (EDA)
- Analyzed numerical and categorical columns.
- Examined data distributions.
- Identified missing values.
- Explored customer demographics and purchasing patterns.

### Step 3: Data Cleaning & Transformation

Performed the following preprocessing operations:

- Identified missing values in the Review Rating column.
- Handled missing ratings using category-wise median imputation.
- Standardized column names.
- Renamed columns for better readability.
- Created an Age Group column using quartile-based segmentation.
- Converted purchase frequency into numerical day intervals.
- Checked for redundant columns and removed Promo Code Used from the analysis dataset.

### Step 4: SQL Analysis using PostgreSQL

Imported the cleaned dataset into PostgreSQL and performed SQL queries to answer business-related questions.

**Key SQL Analysis:**

1. Compared total revenue generated by male and female customers.
2. Identified customers who used discounts but spent above the average purchase amount.
3. Found the top 5 products with the highest average review ratings.
4. Compared average purchase amounts between Standard and Express shipping.
5. Analyzed spending behaviour of subscribed and non-subscribed customers.
6. Identified products with the highest discount usage percentage.
7. Segmented customers into New, Returning, and Loyal categories.
8. Identified the top 3 most purchased products within each category.
9. Analyzed subscription behaviour among repeat buyers.
10. Evaluated revenue contribution across different age groups.

**SQL Concepts Used:**
- SELECT, WHERE, GROUP BY
- ORDER BY
- Aggregate Functions (SUM, AVG, COUNT)
- Subqueries
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER()

### Step 5: Power BI Dashboard

Connected the analyzed customer dataset to Power BI and developed an interactive dashboard to visualize customer shopping behaviour.

The dashboard helps explore customer demographics, purchasing patterns, product performance, and revenue-related metrics.

## 8. How to Run the Project

### Prerequisites

Install the following tools:

- Python 3.x
- Jupyter Notebook
- PostgreSQL
- pgAdmin
- Microsoft Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/Customer-Shopping-Behaviour-Analysis.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Customer-Shopping-Behaviour-Analysis
```

### Step 3: Install Required Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

### Step 4: Run Python Notebook

Open the Jupyter Notebook and execute the cells to:
- Load the dataset.
- Perform EDA.
- Clean and transform the data.
- Connect to PostgreSQL.
- Import the cleaned dataset into the database.

### Step 5: Execute SQL Queries

- Open PostgreSQL using pgAdmin.
- Create the `customer_behavior` database.
- Ensure the cleaned dataset is imported into the `customer` table.
- Execute the SQL queries from the provided SQL file.

### Step 6: Open Power BI Dashboard

- Open Microsoft Power BI Desktop.
- Load the `.pbix` file.
- Refresh the data if required.
- Explore the dashboard and its visualizations.

### Step 7: View Project Documentation

Open the project report and Gamma presentation to explore the methodology, findings, and conclusions.
